#  PassFLOW

Легковесное оффлайн-приложение на Windows Forms для управления учетными записями и генерации TOTP-кодов (двухфакторная аутентификация). Все данные хранятся локально, без использования облачных сервисов.

## ✨ Основные возможности

- **Управление паролями:** Удобное хранение сервисов, логинов и паролей в одной таблице.
- **Генерация TOTP (2FA):** Встроенный генератор одноразовых кодов, совместимый с Google Authenticator, Authy и другими приложениями.
- **Многострочные поля:** Поддержка длинных recovery-ключей и кодов восстановления (с автоматическим переносом строк).
- **Локальное хранение:** Данные сохраняются в защищенный текстовый файл на вашем компьютере.
- **Простой интерфейс:** Интуитивно понятный UI на базе Windows Forms.

## 🛠️ Стек технологий

- **Язык:** C#
- **Платформа:** .NET Framework 4.8
- **UI:** Windows Forms (WinForms)

### 📦 Используемые сторонние библиотеки
- **[Otp.NET](https://github.com/kspearrin/Otp.NET)** — надежная и популярная библиотека для генерации и верификации TOTP/HOTP кодов (реализация стандарта RFC 6238).

## 🚀 Как запустить проект (Инструкция)

Поскольку папка с загруженными библиотеками (`packages/`) игнорируется системой контроля версий (находится в `.gitignore`), для корректной работы проекта необходимо выполнить несколько дополнительных шагов после скачивания.

### Шаг 1: Клонирование и открытие
1. Клонируйте этот репозиторий или скачайте его как ZIP-архив.
2. Откройте файл решения **`WindowsFormsApp1.sln`** (он находится в папке `src/`) с помощью **Visual Studio** (2022 или новее).

### Шаг 2: Восстановление NuGet-пакетов (ОБЯЗАТЕЛЬНО)
При первом открытии Visual Studio может выдать ошибку, что не найден `Otp.NET`. Чтобы это исправить, нужно восстановить пакеты:

**Способ А (Через интерфейс - самый простой):**
1. В **Обозревателе решений** (Solution Explorer) нажмите **правой кнопкой мыши** на название решения (самая верхняя строчка).
2. Выберите пункт **Restore NuGet Packages** (Восстановить пакеты NuGet).
3. Дождитесь окончания загрузки (внизу справа появится уведомление об успехе).

**Способ Б (Через консоль диспетчера пакетов):**
1. Перейдите в меню: **Инструменты** (Tools) -> **Диспетчер пакетов NuGet** -> **Консоль диспетчера пакетов**.
2. Введите команду и нажмите Enter:
   ```powershell
   Update-Package -reinstall
